# Contributing and feedback

LapMind is entering a controlled beta. The application source is currently
private, so this repository is not accepting application-code pull requests.
Useful testing, careful bug reports and product feedback are very welcome.

## Report a bug

Use the Bug report Issue template and include:

- LapMind version;
- Android device and Android version;
- PS4 or PS5;
- GT7 mode/session type;
- whether Discord was connected;
- what happened;
- what you expected;
- the smallest repeatable sequence you know.

Please separate direct observation from interpretation. For example,
`I heard “P 1” during Time Trial` is stronger evidence than `position detection
is broken`.

## Diagnostics and recordings

Do **not** attach a diagnostics ZIP, session export or private screen recording
to a public issue by default. First submit the text-only report and indicate
that private evidence is available. A safe transfer path can then be agreed if
the evidence is needed.

Never share:

- Discord bot tokens, user tokens or passwords;
- signing keys or credentials;
- PlayStation IP addresses;
- private server/channel identifiers;
- personal session data you do not want public.

## Suggest an improvement

The most useful feature feedback begins with a problem or workflow:

- What were you trying to do?
- Were you driving, reviewing or practising?
- What required too much attention or interpretation?
- What is the smallest change that would help?

LapMind is not trying to win a feature-count contest. Suggestions that make the
existing workflow calmer, clearer or more trustworthy are particularly useful.

## Track Lab feedback

Track Lab is explicitly experimental. Feedback should focus on whether the data
was understandable on a phone, whether selecting a lap/corner made sense, and
whether the view led to a useful observation—not on whether it contains as many
charts as a desktop telemetry suite.

## Future track-data contribution

A reviewed contribution-package format for track geometry, corner mapping and
reference traces is being considered, but it does not exist yet. Please do not
submit scraped, copyrighted or third-party replay data as if it were your own.
Future contributions will need provenance, licence/permission and validation
metadata.

## Documentation corrections

Small pull requests that correct a typo, broken public link or clearly false
statement in this public repository are welcome. Larger content changes should
start with an Issue so that the intended product meaning is preserved.

No licence for the private application source is granted by accepting public
documentation feedback here.
