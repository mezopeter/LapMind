# LapMind 0.7.1-beta2 — candidate release notes

> **Not yet publicly released — pending final physical smoke checks.**
> No GitHub Pre-release or public APK is attached yet.

## Highlights

- Fixed false solo P1 behaviour caused by Time Trial/practice context being
  mistaken for a competitive field.
- Improved session semantics so confidently recognized practice is not shown as
  a failed/incomplete race or given a race-position result.
- Expanded experimental Track Lab with richer offline telemetry inspection,
  analytic driving segments and distance-aligned owned-lap comparison.
- Reorganized Settings into a clearer hierarchy and made Sessions browse-first.
- Moved Backup/Restore into a secondary Manage action and removed
  `Delete All Incomplete`.
- Updated the launcher icon and beta information hierarchy.
- Passed the candidate's debug and release JVM verification and private owned-
  lap replay checks.
